⚙️ 数据管理

所有进度、错题、历史记录都保存在本地浏览器（localStorage），换浏览器或清除缓存会丢失。清除浏览器站点数据前，请先备份。

⬇️ 安装为浏览器应用

  1. 用 Chrome / Edge 打开本页面（需要通过网址访问，本地双击打开的 file:// 页面浏览器不允许安装）；
  2. 点击右上角 ⬇️ 安装应用 按钮，或浏览器地址栏右侧的安装图标；
  3. 确认后桌面/开始菜单会出现"有机化学考前刷题"独立图标，打开后是全屏无地址栏的独立窗口；
  4. 手机 Chrome：菜单 →「添加到主屏幕」，效果相同。

提示：直接双击打开本 HTML 文件也能正常刷题（进度照常保存），只是无法"安装成应用"。
